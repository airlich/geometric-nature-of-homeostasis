# geometric-nature-of-homeostasis
Mathematica notebook which creates all results and figures in the article 

Erlich, Zurlo: The geometric nature of homeostatic stress in biological growth. Journal of the Mechanics and Physics of Solids, 2025. https://doi.org/10.1016/j.jmps.2025.106155

Note that the Mathematica notebook requires the Riemannian Geometry & Tensor Calculus package (download here: http://www.inp.demokritos.gr/~sbonano/RGTC/).
